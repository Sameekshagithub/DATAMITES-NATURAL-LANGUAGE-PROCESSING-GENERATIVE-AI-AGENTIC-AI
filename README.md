# DATAMITES – NATURAL LANGUAGE PROCESSING, GENERATIVE AI & AGENTIC AI

## 📌 Overview

This repository contains my **Natural Language Processing (NLP), Generative AI, and Agentic AI** learning materials from **DataMites** as part of my AI Engineer training.

It covers text processing, regular expressions, word vectorization, recurrent neural networks, Transformer architectures, Large Language Models (LLMs), Generative Adversarial Networks (GANs), Variational Autoencoders (VAEs), Retrieval-Augmented Generation (RAG), and Agentic AI.

The repository is intended to organize theoretical concepts, practical Jupyter Notebooks, code implementations, and related datasets for learning and revision.

## 🧠 Key Concepts Covered

| Concept | Description |
|---|---|
| NLP | Enables computers to process and understand human language |
| Regex | Identifies, matches, and extracts text patterns |
| BoW and TF-IDF | Convert text into numerical representations |
| Word2Vec | Learns vector representations of words |
| RNN and LSTM | Process sequential data and learn patterns across sequences |
| Attention | Helps models focus on relevant parts of an input |
| Transformers | Use attention mechanisms to model relationships in sequences |
| BERT | Learns contextual representations of text using a Transformer encoder |
| GPT | Uses autoregressive generation to predict and generate text |
| GAN | Trains a generator and discriminator in competition |
| VAE | Learns a latent representation to generate new data |
| RAG | Combines information retrieval with language model generation |
| Agentic AI | Uses models, tools, and iterative decisions to accomplish tasks |
